### About

Staff Software Engineer with **10+ years** designing and shipping scalable software
products, the last few focused on **AI Engineering and production-grade agentic
systems**. I build end-to-end — frontend, backend, and AI infrastructure — with
React, Node.js, Python, TypeScript, and AWS.

My current focus is **autonomous AI systems powered by LLMs**: LangChain,
LangGraph, Model Context Protocol (MCP), RAG, and multi-agent orchestration —

makes AI work in production: architecture, reliability, observability, evaluation,
latency, and cost.

- 💬 Ask me about: agentic architecture, backend & distributed systems, AWS
