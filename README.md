### Latest: zera.ai — 1st place, Batalha de Agentes (Sep 2026)
 
<a href="https://github.com/dcdaniiel/zera.ai-itau"><img src="https://github.com/dcdaniiel/zera.ai-itau/blob/main/docs/img/banner.jpg" alt="Batalha de Agentes — an Itaú initiative in partnership with Google Cloud and Santo Digital — 1st place: zera.ai" width="50%"></a>
 
Two-day hackathon, an Itaú initiative in partnership with Google Cloud and Santo Digital. Our team built **zera.ai**, a debt-renegotiation
agent that reads the customer's real bank statement, computes what fits the monthly budget with a deterministic engine and only signs
with the customer's explicit confirmation. The LLM explains; it never does the math.
 
- Real data only: 467k transactions from 1,000 customers, segmented with k-means on BigQuery ML
- Google ADK + Gemini 3.8 Flash on Vertex AI, native human-in-the-loop, three-layer guardrails, 101 tests, one Cloud Run service
- Built with an Agent Development Life Cycle (ADLC): contract first, a test per behavior, evaluation on real data, deploy, observe
→ [Repository, architecture (C4) and decisions](https://github.com/dcdaniiel/zera.ai-itau)
